# Cephyr analysis-model 1 decoder

`tools/cephyr_interface.py:decode_interface(data, expected_target=...)` reads
Cephyr C11Interface v1 for AMD64 SysV, AArch64 AAPCS64, and RV64 LP64. The
additive schema is based on LibStone `6a7d52e866db8eb441bb7a4f86ce91253732e740`
(`cornerstone/Cephyr/src/interface.cpp` and `docs/C11Interface.md`). Original
`e10ac69e` projections still decode: they carry no `analysis_model` or
`target_properties`, no `declaration_sites`, and no other analysis records.
Unknown model versions, partial mixed schemas, and unknown clauses are errors.

The decoder returns immutable typed records. The extension adds:

| Where | Fields |
| --- | --- |
| Interface | `analysis_model`, `target_properties` |
| Function, object, typedef | `declaration_sites` in redeclaration order |
| Function | `call_contract`, `behavior`, `memory_safety`, `body_proof` |
| Object | `storage_duration` |
| Integer type, bit field | `value_range` (`minimum`, `maximum`, inclusive) |
| Pointer type | `category` (`object`, `function`) |
| Complete struct or union | `traits` |

This is not an authority boundary. Only the supported target properties and
type representations are accepted. Site counts must match the written storage
history on symbols, and a definition site must match the declaration's
definition state. Parameter annotations must use actual fixed-parameter indexes
and array adjustments must refer to the appropriate pointer type. A `static`
minimum is a caller obligation on that specific declaration; it is not a
measured size. Its presence (`ArrayAccess`) is distinct from a known minimum
(`minimum_elements`). Bracket qualifiers are spelling facts, not alias proofs.
An unprototyped declaration does not imply zero fixed arguments.

`closed-unsigned-expression-v2` describes **this definition** only. The decoder
checks the eligible projected signature and the consistency of the memory safety
and body records, including unique dependency indexes, the expected widths 8,
16, and 31, and `satie` as solver. It cannot verify C bodies, prove the result
itself, or identify which implementation will be linked or called. An
`independent` return dependency is not a guarantee against side channels. A
`proved` width is a range policy, not an untainted value. No status is promoted
to a general effect, pointer, termination, or taint claim. Maps preserve
`unknown` and `disproved` as explicit non-positive statuses; a missing proof
or a missing analysis extension is likewise not positive evidence.

## Portable data

`DeclarationSite.file` and `.line` are untrusted **presumed** labels (including
`#line` substitutions). The decoder bounds and checks their wire shape and
never resolves, opens, or attributes ownership to them. An absolute spelling
does not establish an origin.

Use `Function.portable_analysis_data()` for JSON-recursive semantics data.
It returns `None` on an original v1 projection. Otherwise the keys are
`declaration_sites`, `call_contract`, `behavior`, `memory_safety`, and
`body_proof`; each site is `{"definition": bool, "parameters": [...]}` with
**neither file nor line**. Return dependencies use `{"index": int, "status":
str}` and policies use `{"width": int, "status": str}`. The typed record's field
names are the remaining mapping keys; tuples become arrays and absent records
become `null`. This data has no implicit digest authority: callers that need
identity must separately bind their own schema/version domain, exact symbol,
target, and independently verified subject. Keep it separate from native
representation fingerprints and never publish presumed paths in the catalogue.

## Reproduce

```sh
python3 -B on1x/hir/FFIHandler/tests/test_cephyr_interface.py
python3 -B on1x/hir/FFIHandler/tests/test_cephyr_analysis.py \
  --cephyr "$ANALYSIS_CEPHYR" --legacy-cephyr "$LEGACY_CEPHYR"
```

The options enable checks with real executables. The analysis route test
compares raw C, preprocessed C, and JSON/S-expression syntax round trips on
all three targets. The legacy route verifies that the native graph does not
change and no analysis facts are invented. Offline checks use the existing
legacy fixture and the unedited AMD64 output generated by:

```sh
"$ANALYSIS_CEPHYR" --target=x86_64-linux-gnu --emit-interface=sexp -x c - \
  < on1x/hir/FFIHandler/tests/fixtures/cephyr-interface-analysis.c \
  > on1x/hir/FFIHandler/tests/fixtures/cephyr-interface-analysis.sexp
```
