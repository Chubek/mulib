# Secret rate limit

Supply a trusted clock and maintain persistent limits for the account and client. This local backoff state is not a concurrent global rate limiter. See [secret kernels](secret-kernels.md).

## Source and build reference

[Manual index](index.md) · [Integration guide](integration.md)

| Resource | Location |
| --- | --- |
| Header | [`kernels/mulib-secret-rate.h`](../kernels/mulib-secret-rate.h) |
| Implementation switch | `MULIB_IMPL_SECRET_RATE` |
| Repository-local includes | [mulib-secret-core](mulib-secret-core.md) |
| Complete example | [`examples/mulib-secret-kernels.c`](../examples/mulib-secret-kernels.c) |

The include list includes conditional and implementation-only includes;
it is not a minimal link recipe. Use the example (and any setup header it
includes) for a complete switch configuration. See the integration guide
for dependency placement and platform-specific linking.

Compile the example from the repository root on Linux:

```sh
cc -std=c11 -Wall -Wextra -Wpedantic -Werror -UNDEBUG -Ikernels examples/mulib-secret-kernels.c -pthread -lm -ldl -o mulib-example
```
