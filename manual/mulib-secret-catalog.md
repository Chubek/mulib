# Secret catalogue

Encode and decode sorted development MSC1 entries. Authenticate the bytes before policy use and commit catalogue revisions with their corresponding record changes. The codec does not authenticate its input by itself. See [secret kernels](secret-kernels.md).

The include list includes conditional and implementation-only includes;
it is not a minimal link recipe. Use the example (and any setup header it
includes) for a complete switch configuration. See the integration guide
for dependency placement and platform-specific linking.

Compile the example from the repository root on Linux:

```sh
cc -std=c11 -Wall -Wextra -Wpedantic -Werror -UNDEBUG -Iinclude examples/mulib-secret-kernels.c -pthread -lm -ldl -o mulib-example
```
