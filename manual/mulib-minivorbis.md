# mulib-minivorbis

[Manuals](README.md) · [Library index](index.md)

An original, compact **profile-limited** Ogg/Vorbis encoder and decoder. It does
not embed libvorbis, stb_vorbis, libogg or any third-party codec code. Define
`MULIB_IMPL_MINIVORBIS`, `MULIB_IMPL_AUDIO`, `MULIB_IMPL_XSIMD`; link `-lm` on
Unix. See `examples/modules/minivorbis.c`.

## Exact supported profile

The encoder produces valid Vorbis I, mono/stereo, 8000..192000 Hz, fixed
256-sample blocks, a single short-block mode, uncoupled mapping0, floor1 with
two endpoints, residue1 and two explicit codebooks. A single-entry phrasebook
and 256-entry one-dimensional lookup1 book encode eight-bit spectral residuals.
Floor amplitude adapts per block. No psychoacoustic analysis or target-bitrate
control is provided. This is lossy and relatively high bitrate; signals above
nominal full scale are clipped before analysis. The encoder uses direct MDCTs
with vector dot products, so throughput is lower than FFT-based codecs.

The decoder accepts the **exact setup packet generated by this encoder**.
Different setup/codebooks/window sizes return `UNSUPPORTED`; it cannot decode
arbitrary existing `.ogg` music files. Audio packets may vary floor endpoints,
omit silent channel floors, or use any codewords in this profile. Truncated
audio packets are rejected rather than implementing Vorbis packet peeling.
This restricted implementation is not a full Vorbis-conformance decoder.

The Ogg reader validates capture/version, flags, CRC, serial and page sequence,
lacing and packet continuation. It handles multiple packets per page and packets
spanning pages. Chaining/multiplexing are unsupported. Packets are capped at
1 MiB. Nonfinal completed-page granules must equal decoded frame count; final
granules trim padding. Initial nonzero PCM offsets are unsupported. The decoder
allows one extra block of bounded scratch output before checking the final frame
limit. Empty audio is encoded as a priming packet with EOS granule zero.

## API and ownership

`encode(pcm,options,&bytes)` and `decode(bytes,size,options,&pcm)` require empty
outputs and leave them unchanged on error. Use the audio free APIs. The encoder
uses a deterministic Ogg serial; remultiplexing several independently encoded
streams requires assigning distinct serials and recomputing CRCs.
`options.simd` selects scalar/SSE4.1/AVX2/NEON transform kernels. Working transform
matrix storage is 128 KiB per call, in addition to PCM and encoded data.

Format reference: [Vorbis I specification](https://xiph.org/vorbis/doc/Vorbis_I_spec.html),
including codebook errata and Ogg encapsulation. No implementation source was
copied. The optional FFmpeg oracle compares independently decoded samples and
final granule counts, not just this implementation's own roundtrip.

The include list includes conditional and implementation-only includes;
it is not a minimal link recipe. Use the example (and any setup header it
includes) for a complete switch configuration. See the integration guide
for dependency placement and platform-specific linking.

Compile the example from the repository root on Linux:

```sh
cc -std=c11 -Wall -Wextra -Wpedantic -Werror -UNDEBUG -Iinclude examples/modules/minivorbis.c -pthread -lm -ldl -o mulib-example
```
